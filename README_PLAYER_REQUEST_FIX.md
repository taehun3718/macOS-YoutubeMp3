# 대체 플레이어 HTTP 400 진단 개선

- 최초 검색 `HTTP 200`과 17개 결과는 정상입니다.
- 기본 플레이어 응답은 `formats=24, url=0, cipher=0, SABR=true`입니다. 직접 다운로드 가능한 URL이 없습니다.
- 기존 대체 플레이어는 `clientName=WEB_SAFARI`를 고정하고 `HTTP 400` 응답 본문을 버렸습니다.
- 수정본은 페이지에서 수집한 클라이언트 버전을 사용하며 `clientName=WEB`으로 전송하고, 대체 요청 실패 시 HTTP 오류 메시지를 로깅합니다.
- 민감 정보(토큰/쿠키/URL)는 로그에 출력하지 않습니다.
- **이 수정은 SABR 다운로드 엔진을 구현하지 않습니다.** 대체 요청이 정상 처리되더라도 `direct=0`인 경우 MP3 변환은 여전히 시작할 수 없습니다.
- YouTube 이용약관과 콘텐츠 다운로드 권한을 준수해야 합니다.
- Xcode 실제 빌드, YouTube 다운로드 성공은 현재 환경에서 확인하지 못했습니다.
